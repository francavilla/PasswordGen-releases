Privacy

Non esiste un server di PasswordGen

Nessuno raccoglie i tuoi dati, perché non c'è un posto dove raccoglierli. Niente pubblicità, niente statistiche, niente tracciamento.

Le funzioni che usano la rete sono facoltative e spente di base: le attivi tu, quando vuoi.

  • Storico e frasi segrete cifrati sul tuo dispositivo.
  • Controllo password compromesse: si invia solo l'inizio dell'impronta, mai la password.
  • Sincronizzazione con un file cifrato che solo tu puoi aprire.

Domande frequenti

Prima di cominciare

Serve un account?

No. L'app funziona subito, senza registrazione. Un account Google serve solo se vuoi sincronizzare PC e telefono tramite Google Drive, ed è facoltativo.

Dove sono salvate le mie password?

Solo sul tuo dispositivo, nello storico cifrato (con le protezioni di Windows o di Android). Le proposte generate non vengono salvate: resta solo quella che registri tu con «Ho cambiato la password».

Windows mi dice «Windows ha protetto il PC». È normale?

Sì: il programma non è firmato digitalmente e Windows lo segnala per qualsiasi software poco diffuso. Premi «Ulteriori informazioni» e poi «Esegui comunque». Se vuoi, prima controlla l'impronta SHA-256 dello zip, riportata sotto il pulsante di download.

Come faccio ad aggiornare l'app?

Nelle impostazioni puoi attivare il controllo delle nuove versioni (spento di base). Quando ce n'è una, compare un avviso con il pulsante «Scarica». L'app non scarica né installa niente da sola.

Cosa succede se dimentico la frase segreta della sincronizzazione?

Non si può recuperare: il file cifrato non si apre più. Lo storico locale resta sul dispositivo e puoi creare un nuovo file di sincronizzazione.
